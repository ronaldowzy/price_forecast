# Data Privacy

本文档说明仓库中数据文件的内容和隐私状况。

## `data/` 目录

包含山东省电力市场的聚合运行数据：

| 文件 | 说明 | 大小 |
|---|---|---|
| 价格预测数据集.csv | 主数据集 | ~11 MB |
| 价格预测数据集.xlsx | 同上的 Excel 格式 | ~11 MB |
| 价格预测数据集_bak1.csv | 数据集备份 | ~6 MB |
| 价格预测输入数据.csv | 模型输入数据 | ~9 KB |
| 价格预测输入数据_bak1.csv | 输入数据备份 | ~17 KB |

### 数据内容

数据字段包括：
- 负荷预测值
- 风电/光伏出力
- 日前电价 / 实时电价
- 节假日标记
- 温度等气象数据

### 隐私评估

- **无个人信息 (PII)**：数据为省级电网聚合运行数据，不包含个人姓名、地址、联系方式等
- **无商业机密**：数据为公开市场运行数据
- **无凭据信息**：数据文件中不包含 API 密钥、密码或认证令牌

### 建议

虽然数据本身不含敏感信息，但 **27 MB 的数据文件** 对 Git 仓库来说体积较大。建议：

1. **使用 Git LFS** 管理大文件：
   ```bash
   git lfs install
   git lfs track "data/*.csv"
   git lfs track "data/*.xlsx"
   ```

2. **或从仓库排除**（在 `.gitignore` 中取消注释）：
   ```
   data/
   ```
   用户可通过其他渠道获取数据。

3. **清理备份文件**：`_bak1` 文件为历史备份，如不再需要可考虑删除。

## `old/backtest_outputs/` 目录

包含历史回测的预测值与真实值对比数据，无隐私风险。

## `getData/` 脚本

### 已处理

脚本中原本硬编码的 SGCC 平台认证凭据（`Admin-Token`、`X-Ticket`、`XHXT_SESSIONID`）已替换为环境变量读取方式。

### 使用方式

运行数据获取脚本前，需设置环境变量：

```bash
export SGCC_TOKEN="your-admin-token"
export SGCC_SESSIONID="your-session-id"
```

### 注意事项

- 这些凭据是 SGCC 山东电力市场平台的会话令牌，具有时效性
- 请勿将有效凭据提交到版本控制中
- 建议使用 `.env` 文件（已在 `.gitignore` 中排除）管理本地凭据
